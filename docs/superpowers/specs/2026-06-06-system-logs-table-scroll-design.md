# 系统日志表格内部滚动设计

## 目标

在桌面端“设置 > 系统日志”页面中固定“操作记录”标题区域。日志记录超过可视高度时，仅滚动 Element Plus 表格主体，右侧页面标题不随记录滚动。

## 实现范围

- 仅修改 `frontend/src/views/settings/SystemLogsView.vue` 及对应测试。
- 系统日志页面使用纵向 Flex 布局，占满右侧内容区可用高度。
- 标题区域保持自然高度，不参与收缩。
- 表格卡片占用标题下方剩余空间，并允许内部子元素正确收缩。
- 有数据时，`el-table` 高度设为 `100%`，由 Element Plus 生成表格主体内部纵向滚动条。
- 加载骨架和空状态继续显示在同一卡片区域，不改变接口调用、字段或业务逻辑。
- 移动端保持现有页面自然滚动行为，避免小屏固定高度影响内容查看。

## 测试与验收

- 组件测试确认系统日志表格启用满高布局，并具有独立页面和卡片样式类。
- 桌面端端到端测试构造超量日志，确认：
  - 系统日志页面外层不产生纵向滚动；
  - 表格主体可纵向滚动；
  - 滚动后“操作记录”标题位置保持不变。
- 运行完整前端单元测试和生产构建。
- 更新 Docker Compose 运行环境，并在 `http://127.0.0.1:8080/` 完成可视化检查。

## 非目标

- 不修改日志接口、数据字段和排序逻辑。
- 不修改角色分配页、任免看板或通用 `.table-card` 行为。
- 不新增分页、筛选或日志查询功能。
