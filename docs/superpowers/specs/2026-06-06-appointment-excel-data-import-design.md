# 任免数据 Excel 一次性导入设计

## 目标

将 `D:\AIAPP\素材\导入数据.xlsx` 第一张工作表“导入数据”中的 75 条数据导入当前 Docker MySQL 数据库，确保“党群人力部 > 任免看板”字段与 Excel 表头对应，点击姓名查看“任免审批表”时，对应字段能够正确回填。

## 已核对的数据情况

- 工作表数据范围为 `A1:W77`，前两行为分组表头，第 3 至 77 行共 75 条数据。
- 当前数据库中有效任免记录为 0 条。
- 所属公司均为“集团公司”。
- 所属部门均属于系统现有 11 个部门选项。
- “序号”为 1 至 75，且没有重复。
- 身份证号均为合法的 18 位字段格式，可解析出生年月。
- “联系方式（手机长号）”和“学位”两组列全部为空。
- 字段长度均未超过当前数据库列限制。

## 任免审批表补充映射

- `birth_date`：从身份证号第 7 至 14 位解析，格式为 `YYYY-MM-DD`。
- `position_name`、`graduation_school`、`address`：历史非空数据库列写入空字符串，不用于当前看板。
- `approval_authority_opinion`：写入系统默认值“此表信息已认定”。
- Excel 未提供的籍贯、出生地、入党时间、参加工作时间、健康状况、熟悉专业有何专长、拟任职务、拟免职务、简历、奖惩情况、年度考核结果、任免理由、家庭成员、呈报单位、意见日期和填表人等字段保持空值。
- 不生成照片文件记录，证件照保持为空。

## 年龄兼容

- 新增 Flyway 结构迁移，仅为 `appointment_record` 增加可空 `age INT` 字段。
- 实体和响应逻辑优先返回数据库中的 `age`；当 `age` 为空时，继续按 `birth_date` 动态计算周岁。
- 当前新增任免审批表不增加年龄输入框，新建记录的 `age` 保持为空，继续使用原有动态计算逻辑。
- 导入记录后续编辑时不主动覆盖已保存的 Excel 年龄，避免无关编辑改变看板原始数据。

## 一次性导入

- 75 条数据不写入 Flyway，避免新环境自动重复导入业务数据。
- 生成可审计的一次性 SQL 文件，并只在当前 Docker MySQL 中执行。
- 导入前再次校验当前有效任免数据数量为 0；若不为 0，则中止执行，防止重复或覆盖。
- SQL 使用事务执行，任一条失败则整体回滚。
- `created_by`、`updated_by` 关联当前 `superadmin` 用户。
- 不调用新增接口，因此不为 75 条历史数据生成 75 条“新增操作”系统日志。

## 验证与回滚

- 后端测试覆盖：持久年龄优先返回、年龄为空时仍按出生日期计算。
- 导入后核对数据库有效记录总数为 75、序号范围为 1 至 75、公司和部门分布与 Excel 一致。
- 通过后端列表和详情接口抽查首条、中间条、末条记录。
- 在浏览器检查任免看板，并点击姓名核对任免审批表字段。
- 导入 SQL 单独保留本批次标识；如需回滚，仅删除本批次 75 条记录，不影响其他业务数据。
